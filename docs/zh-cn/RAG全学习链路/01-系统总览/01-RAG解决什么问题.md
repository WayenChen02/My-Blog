# 01-RAG是什么?解决了什么问题?

## RAG是什么?

RAG(Retrieval-Augmented Generation，检索增强生成)，它是一种基于“先检索，再生成”的大模型应用框架，通过对接外部知识库将检索到的数据注入到prompt中发送给大模型基于真实资料返回最准确的回答。

## RAG解决了哪些问题

想要知道RAG解决了哪些问题，就要清楚大模型现有的问题有哪些：
    - 1.数据的实时性：大模型只知道自己被训练时候的数据，之后新的数据大模型无法得知；
    - 2.幻觉问题：大模型存在自己不知道这个问题的答案却还是在一本正经的胡说八道的情况；
    - 3.无法得知企业私有数据：大模型无法得知企业内部的私有数据，比如企业的规章制度，销售额，营业额等数据。
RAG通过对接外部知识库，基于真实资料让大模型能返回最准确的回答，以此解决了以上几种问题

## RAG的流程

RAG流程分为两大阶段：

- 1.索引阶段:
  - 1.收集数据
  - 2.清洗并对数据进行分块
  - 3.将每块数据进行向量化
  - 4.将向量化的数据存储在向量数据库中
- 2.检索增强阶段：
  - 1.将用户的问题拆解进行向量化
  - 2.从向量数据库中查询到和用户问题最接近TopK向量
  - 3.基于这些向量从存储原文的数据库中找到原文注入到prompt中
  - 4.大模型基于这些真实数据原本回复准确的数据

## 总结

RAG是一种基于“先检索，再生成”的大模型应用框架，通过将真实数据向量化和用户问题进行比对，找到最相近且能够回答问题的数据，注入prompt发送给大模型，让大模型基于真实资料进行回答。
