# JVM 简介

## 什么是 JVM？

JVM（Java Virtual Machine）是 Java 虚拟机的缩写，它是 Java 平台的核心组成部分。JVM 负责将 Java 字节码转换为特定平台的机器码并执行，实现了 Java 的跨平台特性。

## JVM 的架构

### 1. 类加载子系统

负责将.class 文件加载到内存中，并生成对应的 Class 对象。

### 2. 运行时数据区

包括以下几个部分：

- **方法区**：存储类信息、常量、静态变量等
- **堆**：存储对象实例
- **栈**：存储局部变量和方法调用
- **程序计数器**：记录当前执行的字节码位置
- **本地方法栈**：支持本地方法调用

### 3. 执行引擎

负责执行字节码，包括：

- **解释器**：逐行解释执行字节码
- **JIT 编译器**：将热点代码编译为本地代码
- **垃圾收集器**：自动回收不再使用的内存

## JVM 的工作原理

1. **编译**：Java 源代码通过 javac 编译器编译为字节码（.class 文件）
2. **加载**：类加载器将字节码加载到内存
3. **验证**：验证字节码的正确性
4. **准备**：为类变量分配内存并设置默认值
5. **解析**：将符号引用转换为直接引用
6. **初始化**：执行类初始化代码
7. **执行**：执行字节码或本地代码
8. **退出**：程序执行完毕后退出

## 垃圾回收
### 垃圾回收的原理

垃圾回收器负责回收不再使用的内存，主要步骤包括：

1. **标记**：标记出需要回收的对象
2. **清除**：清除标记的对象
3. **压缩**：整理内存空间

### 常见的垃圾回收器

- **Serial GC**：单线程垃圾回收器
- **Parallel GC**：多线程垃圾回收器
- **CMS GC**：低延迟垃圾回收器
- **G1 GC**：区域化垃圾回收器
- **ZGC**：低延迟垃圾回收器

## JVM 调优

### 内存设置

- **堆内存**：通过 -Xms 和 -Xmx 设置
- **栈内存**：通过 -Xss 设置
- **方法区**：通过 -XX:MetaspaceSize 和 -XX:MaxMetaspaceSize 设置

### 垃圾回收器选择

根据应用场景选择合适的垃圾回收器：

- **吞吐量优先**：选择 Parallel GC
- **低延迟优先**：选择 CMS GC 或 ZGC
- **大内存场景**：选择 G1 GC 或 ZGC

## JVM 监控和诊断

### 常用工具

- **jps**：查看 Java 进程
- **jstat**：监控 JVM 统计信息
- **jmap**：生成堆转储快照
- **jstack**：生成线程快照
- **jconsole**：图形化监控工具
- **VisualVM**：综合监控工具

### 常见问题分析

- **内存泄漏**：使用 jmap 生成堆转储，使用 MAT 分析
- **线程阻塞**：使用 jstack 分析线程状态
- **CPU 使用率高**：使用 jstack 分析线程状态

## 总结

JVM 是 Java 程序的运行环境，它提供了内存管理、垃圾回收、字节码执行等核心功能。了解 JVM 的工作原理和调优方法，对于开发高性能、可靠的 Java 应用程序至关重要。
